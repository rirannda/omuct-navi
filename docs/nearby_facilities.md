# 高専祭向けの施設検索と現在地

通常版ではトイレ・ゴミ箱の検索ボタンを表示しません。
高専祭用データへ差し替えるときに、`src/data/config.ts`の`mode`を`festival`にします。
現在は`normal`のままです。POI・マーカーの実データや公開階は変更していません。

```ts
import type { MapDataConfig } from './types';

export const mapDataConfig: MapDataConfig = { mode: 'festival' };
```

## 検索UI

ボトムシートの中段にバリアフリーの切り替えを置き、高専祭版では同じ欄に
「近くのトイレを表示」「近くのゴミ箱を表示」を並べます。
高専祭版のトイレ・ゴミ箱ボタンは下段から表示し、押すと中段で検索条件を開きます。
下段の高さは、文字サイズに合わせて入力欄と施設ボタンが収まるようにします。
バリアフリーは中段のみ、トイレ・ゴミ箱ボタンは下段・中段に表示します。
開始済みの施設検索の条件・結果は上段でも操作できます。

- GPSオフでは「現在の建物」を選択すると、その建物の施設を全件表示します。
  詳細図のない管理棟なども選択できます。屋外の施設は「屋外」で探せます。
- GPSオンで取得中なら待機表示にし、取得後は地図上の直線距離で近い順に最大5件を表示します。
- トイレは「指定なし」「男子」「女子」「バリアフリー」で絞り込めます。
- 該当なしの場合はその旨を表示します。結果を選ぶと、施設情報と対応する階を開きます。
  「ここへ行く」から既存の経路検索へ進めます。
- 検索中の地図では結果の施設マーカーに絞り込みます。現在選択中・出発地・目的地の
  マーカーは維持します。「検索を閉じる」と通常表示に戻ります。
- 一覧には建物・階を表示します。階が異なる施設は結果を選んで表示階を切り替えます。

GPSの距離は経路の長さやメートル換算値ではありません。校内地図の座標で比較します。
GPS更新で結果は更新しますが、ユーザーが地図を操作できるよう、毎回カメラを動かしません。

## マーカーに設定する項目

`categoryId`はトイレに`toilet`、ゴミ箱に`trash`を指定します。
トイレの`toiletType`には`men`・`women`・`accessible`を指定してください。
種別を省略したトイレは「指定なし」でのみ検索できます。
アイコン画像のファイル名や施設名から種別を推測しないため、独自画像でも検索できます。

```ts
// markers.tsのトイレの項目に追加します。
categoryId: 'toilet',
toiletType: 'women',
```

マーカーの追加方法と既存POIの移行手順は[施設マーカーの登録](markers.md)を参照してください。

## GPSの接続口

検索ボタンと現在地ボタンから、初回の説明確認とブラウザの位置情報の許可へ進みます。
同意が保存済みでも、ブラウザの許可が必要ならアプリの確認モーダルを先に表示します。
「同意して利用」でモーダルを閉じてからブラウザの測位APIを呼びます。
同意後は`watchPosition()`で取得し、3つの基準点から校内地図へ変換します。
GPSを使わない場合・取得できない場合は、これまでどおり建物を指定して検索します。
初回確認は検索ボタンと現在地ボタンで共有します。利用するかの選択結果以外は永続保存しません。

基準点、追従の条件、ポリシーの表示場所は[GPSと現在地](geolocation.md)を参照してください。
変換済みの地図座標を直接通知するAPIも維持します。

```ts
// GPSオン・取得中
navigation.setGpsLocation({ enabled: true, position: null });

// 校内地図のNodeと同じ座標系へ変換した位置を通知
navigation.setGpsLocation({ enabled: true, position: { x: 600, y: 750 } });

// GPSオフ・許可されなかった場合など
navigation.setGpsLocation({ enabled: false });
```

緯度・経度をそのまま`x`・`y`に渡さないでください。
不正な座標は受理しません。GPSのオン・オフを変更したら、施設検索の建物指定を解除します。
GPSオフへ戻ったときは利用者に現在の建物を選び直してもらいます。

## 現在地ボタンと帰属表示

現在地ボタンは右下、Leafletの帰属表示は左下に配置します。
ボトムシートの高さに合わせて両方を上へ移動し、上段では地図操作UIを隠します。
GPSオフでも現在地ボタンを操作でき、初回確認から位置情報の取得を開始します。
取得中だけボタンを無効にし、取得後は見えている地図領域の中央へ移動します。
ルート案内中は追従も再開します。地図操作で追従だけを解除し、取得自体は継続します。

テストなどでデータを注入する場合は、
`createNavigationState({ graph, pois, markers, config: { mode: 'festival' } })`で有効化できます。
