# GPSと現在地

位置情報の取得、校内図への座標変換、施設検索、経路と現在地の照合はブラウザ内で行います。
運営サーバー・アクセス解析・外部地図APIへ位置を送信しません。新しい外部サービスや依存パッケージは追加しません。

## 操作と確認

- 「近くのトイレを表示」「近くのゴミ箱を表示」「ルート検索」と右下の現在地ボタンは、初回利用時に共通の確認ダイアログを開きます。
- 操作の順序は「GPSを使う機能を起動 → アプリの確認モーダル → ブラウザの位置情報の許可」です。「同意して利用」でアプリのモーダルを閉じてから測位APIを呼びます。確認前や「使わない」を選んだ場合は測位しません。
- 利用するかどうかの選択結果だけを`localStorage`の`omuct-navi.location-consent.v1`へ保存します。位置や履歴は保存しません。保存が制限されている場合は、ページ内だけで選択結果を保持します。
- 「使わない」を選んだ後の施設検索では確認を繰り返さず、建物指定を使います。現在地ボタンを押すと利用を選び直せます。
- 同意が保存済みでも、測位の再開前にブラウザの許可状態を確認します。許可を再度求める状態ならアプリのモーダルを先に表示します。許可状態の照会自体では測位や許可要求を行いません。
- アプリで同意済みかつブラウザで許可済みの場合、または測位中のボタン操作では、確認を繰り返しません。許可状態を照会できないブラウザでは、測位を開始する前にアプリの確認を表示します。
- ブラウザの許可画面の表示はブラウザの設定に従います。すでに許可済みなら表示されず、拒否済みの場合はサイト設定からの変更が必要になることがあります。
- 位置情報を使わない場合、施設検索は建物の手動指定へ進みます。拒否・非HTTPS・非対応・測位失敗・範囲外・精度不足でも手動操作を利用できます。
- 現在地ボタンは取得した位置を、ボトムシートを除いた地図の中央へ移動します。地図には現在地の青い点と測位精度の範囲を表示します。

## 経路案内中の追従

ルート検索の成功後、または現在地ボタンの押下後は追従を有効にします。
現在地が表示中の階の経路から10m相当の地図座標の許容幅に入る場合に限り、地図の中心を現在地へ移します。
縮尺の最大値で換算した暫定の判定しきい値です。実測した精度や保証値ではありません。
ルート外では現在地の表示だけを更新し、利用者が操作せず経路へ戻れば追従を再開します。
追従開始時は現在地ボタンと同じ縮尺へ拡大し、全体表示で地図の移動制限に当たって現在地がシートに隠れることを防ぎます。

位置情報の確認ダイアログを除き、地図・シート・パネルへのポインター操作、ホイール、地図操作やボタン実行のキーで追従を解除します。
地図がGPS更新・検索結果・シートの高さ変更で自動的に移動した場合は、利用者の操作として扱いません。
測位待ち・地図読み込み中の手動操作も尊重し、遅い位置更新でカメラを奪いません。
測位の継続とカメラの追従は別の状態です。

案内を終了し、施設検索もしていない場合は測位を停止します。
施設検索を閉じて案内もしていない場合や、地図コンポーネントの破棄時も停止します。
シート最上段の「位置情報の利用を停止」からも停止でき、保持している位置を消去します。
確認済みの利用者が再びルート検索を実行すると測位を再開します。

GPSから建物の階は推定しません。階の選択は既存の階コントロールで行います。
画面ロック中・別タブ・別アプリ使用中の連続案内は保証しません。

## 暫定の基準点と補正

`src/data/geolocation.ts`の3点を編集すると補正できます。
度分秒はユーザー提供のGoogle Maps衛星写真由来です。測量値ではなく、実地での検証と補正が必要です。
工場棟は添付画像の縦長の長方形と`master.svg#fac-bldg_1`の形状・縦横比を照合しています。

| 地点         | 緯度         | 経度          | SVG座標       | 地図座標      |
| ------------ | ------------ | ------------- | ------------- | ------------- |
| 正門の左下   | 34°46′08.5″N | 135°37′43.9″E | (610, 1566.5) | (610, 133.5)  |
| 工場棟の右上 | 34°46′13.8″N | 135°37′50.6″E | (1250, 856.5) | (1250, 843.5) |
| 教養棟の右上 | 34°46′12.7″N | 135°37′44.0″E | (581, 1027.5) | (581, 672.5)  |

SVGはYが下向き、Node・Leafletの地図座標は上向きなので、`地図のy = 1700 - SVGのy`です。
緯度・経度を局所的な東西・南北の距離に換算し、3点によるアフィン変換で回転・縮尺・ずれを対応させます。
変換は校内向けで、広域の地理座標変換には使用しません。基準点が未設定・一直線などで変換を作れない場合は現在地を推測しません。
校内図は模式図なので、3点が一致しても全地点で一致する保証はありません。離れた複数地点で検証してください。

`src/lib/states/geolocation.svelte.ts`では精度が50mより悪い位置と30秒以上古い取得結果を表示に使いません。
最初に粗い位置が返った場合は最大15秒間、精度の改善を待ちます。改善しない場合は停止します。
50mは誤った施設や経路への追従を避けるための暫定の上限です。
追従判定は精度の範囲を無制限に広げず、10mの許容範囲を使用します。

## 説明とポリシーの表示場所

表示場所は次の構成を採用しています。

1. 初回確認ダイアログに、利用目的・継続取得・端末内処理・送信と履歴保存をしないこと・手動操作の選択肢を記載します。
2. 詳細な位置情報の説明は`/privacy`に置き、確認ダイアログから別タブで開けます。確認中の検索操作を中断しません。
3. 地図のシートを最上段へ開くと、説明ページへのリンクと位置情報の利用停止を表示します。通常の検索オプションの高さは増やしません。

地図への固定フッターは地図領域を狭くし、中段の常設リンクは既存の検索欄を高くするため採用していません。
`/privacy`はこの機能の情報の取り扱いを説明するページです。サイト全体の運営者情報や問い合わせ先を推測して記載してはいません。
ブラウザ・OSの測位サービスによる情報の取り扱いは、それぞれの提供元の方針に従うことも明記しています。

## 実装の所有範囲

- `geolocation.svelte.ts`: アプリの確認・ブラウザの許可状態の照会・測位監視・エラー・停止。通信や位置の永続保存は行いません。
- `geolocationProjection.ts`: 緯度・経度と精度から校内図の座標への変換。
- `routePosition.ts`: 表示中の階の経路と現在地の距離判定。
- `locationLayer.ts`: 現在地と精度範囲の描画・破棄。
- `navigation.svelte.ts`: GPSの座標と検索・経路への接続、現在地への移動要求。
- `Map.svelte`: カメラの移動と追従、利用者操作による解除、測位・描画資源の破棄。

仕様の根拠: [Geolocation API](https://www.w3.org/TR/geolocation/)、[位置情報を受け取る側のプライバシー指針](https://www.w3.org/TR/geolocation/#privacy_for_recipients)。
